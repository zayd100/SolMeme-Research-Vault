# Case Study: 20 -> 350 and Back
*Your own history, turned into lessons.*

## Timeline (as you told it)

2. Lost it all - suspected a bundle; no filters, bought off Pump.fun trending

## Lessons
- **Trending tab = late.** By then insiders are often exiting. ([[Attention Economy and CT]])
- **No filters** = no edge. Use [[Pre-Trade Checklist]].
- **No exit plan on a 17x** = giving it all back. Use [[The Big Win Protocol]].
- **Signals**: you were maybe late. Measure caller timing. ([[Call Channels and Payouts]])
- Suspected bundle? Do a post-mortem with [[Bundle Detection Checklist]].
