# Tools and Trackers
*Tool market changes fast; reviews are often affiliate-driven (referral codes). Verify features yourself.*

| Need | Tool (examples) | Note |
|---|---|---|
| Token/bundle/early buyers | GMGN, RugCheck.xyz | RugCheck reports bundled & sniper supply separately |
| Raw chain verification | Solscan | sort earliest txs |
| Cluster visual | Bubblemaps | general knowledge, verify |
| Bundle API / market-wide | Raiden API (terminal.raiden.wtf) | 6 months rolling data, history since 1 May 2026 (per its blog) |
| Wallet/PnL tracking | Cielo, GMGN | check if wallet is a bot/insider |
| Charts | DexScreener, Birdeye | |
| Terminals/apps | [[FOMO App]], Axiom, Pump Terminal | fees ~0.5% on Fomo Solana |
| Dashboards | Dune (@oladee, @Adam_Tehc) | see [[Data Reality Check]] |
| Journal | Obsidian ([[Trade Journal]]) | |

## Rule
- Two independent tools must agree before you trust a "clean" read.
- Fund a **separate trenches wallet**. See [[Wallet Security and Scams]].
