# Wallet Security and Scams
## Setup
- **Trenches wallet** (small funds) separate from your vault/main wallet.
- Move profits out. See [[The Big Win Protocol]].
- Never share seed phrase. No "support" DMs, ever.

## Common scams in this scene
- Fake "alpha" DMs with links -> wallet drainers
- Fake token CAs (copycats)
- Fake terminals/apps/airdrop claim sites
- "Send 1 SOL get 2" / giveaway replies under big accounts
- Fake KOL accounts (lookalike handles)
- Pay-for-calls groups that front-run you ([[Call Channels and Payouts]])

## Habits
- Read what you sign. If a tx asks for broad approvals, stop.
- Bookmark official sites. Don't click from DMs/replies.
- Use 2FA, hardware wallet for the main stash.
