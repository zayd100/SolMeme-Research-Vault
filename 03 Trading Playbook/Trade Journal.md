# Trade Journal
Log every trade. This is how you find edge.

## Fields (see [[Trade Log Template]])
- Date/time, token, CA, venue
- Why (one sentence), source of idea (caller/KOL/own)
- Bundled %, top-10 holders, MOVE score ([[Spotting Winners]])
- Entry size (units), exit plan
- Result (net of fees), emotion, rule broken?

## Weekly review ([[Weekly Review Template]])
- Win rate, avg win / avg loss, net PnL, max drawdown
- Which callers/sources were early vs late
- Top 3 mistakes -> one rule change

## Link style (Obsidian)
- Create a note per trade or daily note; link to [[Pre-Trade Checklist]], tokens, callers.
- Use tags: #win #loss #rule-broken #bundled
