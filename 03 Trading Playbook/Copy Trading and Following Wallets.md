# Copy Trading and Following Wallets
Fomo-style feeds and wallet trackers show what others buy as they buy.

## Pros
- Learn how experienced traders size and exit
- Discover narratives early

## Cons
- **Latency**: you're behind the wallet; followers = exit liquidity
- Wallet may be a bot, insider, or KOL farming followers
- Realized vs unrealized PnL can mislead; survivorship bias
- Wallets can rotate to fresh wallets

## Rules
- Use as a **signal, not a trigger**. Run [[Pre-Trade Checklist]].
- Track each wallet/caller in a sheet: entry time vs yours, result after delay.
- Limit follows to a few; review monthly.
- Check if wallet is part of a cluster ([[Bundling]]).
